# Prompt Engineering with Gemini

> **INGETIS · Master-level studies · 2026–2027**  
> Portfolio maintainer: **Mohammed Alaa Eddine GUERBOUZ**  
> Type: classroom lab / adapted educational material

## Problem being explored

How can prompt design and generation settings improve the usefulness, consistency and control of LLM responses?

## Approach implemented / explored

- Configure and call the Gemini SDK from a Colab notebook
- Compare prompting styles and experiment with generation controls
- Explore reasoning-oriented options and code-generation prompts
- Inspect responses and reflect on differences between prompt variants

## Technical stack

`Python`, `Google Gen AI SDK`, `Gemini API`, `Google Colab`.

## What this demonstrates

- Understanding of the concepts and implementation pattern explored in the notebook.
- Practical interaction with model APIs, data processing tools and/or agent workflows.
- Ability to discuss the trade-offs and operational constraints of this technique.

## Run the practical notebook

1. Open [`gemini-prompt-engineering.ipynb`](./gemini-prompt-engineering.ipynb) with Google Colab or Jupyter (Colab is preferred where configured by the original notebook).
2. Install the packages in its setup cells; run cells in order.
3. Configure model credentials through **Colab Secrets** or supported environment variables; never commit secrets.
4. Confirm model names, API quota and package versions supported by your own environment.

**Prerequisites**

- A Gemini API key in Colab secrets or an environment variable
- Internet access and access to compatible Gemini models

## Limitations and honest scope

- Prompt results depend on model versions and are nondeterministic
- Not a benchmark of prompt quality across models

**Evidence and results:** Educational experiments and model responses; no independently verified quantitative improvement.
